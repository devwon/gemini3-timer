# Gemini 3 서울 해커톤 타이머

해커톤 종료(17:00 KST)까지 남은 시간을 보여주는 카운트다운 타이머입니다.

## Web

https://hackathon.devwon.ai/gemini-3-seoul

## Claude Code Skill

Claude Code에서 `/gemini3-timer`로 바로 사용할 수 있습니다.

### 설치

```bash
mkdir -p ~/.claude/commands && curl -o ~/.claude/commands/gemini3-timer.md https://raw.githubusercontent.com/devwon/gemini3-timer/main/claude-skill/gemini3-timer.md
```

### 사용

Claude Code에서 `/gemini3-timer` 입력

- 브라우저에서 카운트다운 타이머 자동 오픈
- 터미널에 남은 시간 표시
